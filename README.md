Rock Paper Scissors Game
A simple Rock Paper Scissors game built using HTML and JavaScript.
Features

* Player can choose Rock, Paper, or Scissors
* Computer generates a random choice
* Displays both player and computer choices
* Determines the winner
* Displays draw, win, or loss result

Technologies Used

* HTML5
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Choose Rock, Paper, or Scissors to play.
